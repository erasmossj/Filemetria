# Font Sources

Fontes do HUD em `assets/fonts/`, baixadas do repositório oficial do Google Fonts ([google/fonts](https://github.com/google/fonts)). Os arquivos foram renomeados para `snake_case`. O texto da licença de cada família está no `OFL.txt` da pasta.

| Fonte | Arquivos | Uso | Source | Author | License |
|---|---|---|---|---|---|
| Bebas Neue | `bebas_neue/bebas_neue_regular.ttf` | Títulos, tempo e números das retas | [Google Fonts - Bebas Neue](https://fonts.google.com/specimen/Bebas+Neue) | Dharma Type | SIL OFL 1.1 |
| Barlow | `barlow/barlow_medium.ttf`, `barlow_semibold.ttf`, `barlow_bold.ttf` | Textos, teclas e comprimentos | [Google Fonts - Barlow](https://fonts.google.com/specimen/Barlow) | The Barlow Project Authors (Jeremy Tribby) | SIL OFL 1.1 |
