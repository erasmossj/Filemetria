# Icon Sources

## Ícones

Ícones de interface em `assets/sprites/`. O SVG original usa `stroke="currentColor"`, que o importador do Godot não entende, então a cor do traço foi trocada para branco (`#ffffff`) e o tamanho para 48 px. A cor final vem do `modulate` no Godot. O comentário de licença do arquivo original foi mantido.
