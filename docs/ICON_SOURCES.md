# Icon Sources

Ícones de interface em `assets/sprites/`. O SVG original usa `stroke="currentColor"`, que o importador do Godot não entende, então a cor do traço foi trocada para branco (`#ffffff`) e o tamanho para 48 px. O comentário de licença do arquivo original foi mantido.
